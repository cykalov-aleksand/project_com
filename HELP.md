# Проектная работа 
## Тема: «Web сервис по ремонту сменных радиоэлементов»
Исполнитель: Цыкалов Александр

Описание:
Сервис представляет из себя програмное обеспечение, по доступу к базе данных тестируемых элементов, обеспечивает настройку,
сохранение и передачу данных, по доступному COM порту (а также его настройку), команд управления микроконтроллерами, тестовой установки.
